# PSController (PSControllerPatcher)

Shows PlayStation button icons (✕ ○ □ △, L1/R1/L2/R2, L3/R3) instead of Xbox ones in MIMESIS.
By Mohamed Darwesh ([@medovanx](https://github.com/medovanx)).

## Use
1. Close the game.
2. Put `PSControllerPatcher.exe` next to `MIMESIS.exe` and run it.
3. Choose install (`i`) or uninstall (`u`).

## How it works
Your PS controller is emulated as an Xbox controller, and the game shows PlayStation icons:

1. **DS4Windows** (output: **Xbox 360**) turns the PS4/PS5 controller into a virtual Xbox pad. The game reads that reliably.
2. **This patch** makes the game use that Xbox pad and swaps every button icon for its PlayStation version.

| Your button | Game sees | Icon shown |
|---|---|---|
| ✕ ○ □ △ | A B X Y | ✕ ○ □ △ |
| L1 / R1 (upper buttons) | LB / RB | L1 / R1 |
| L2 / R2 (lower triggers) | LT / RT | L2 / R2 |
| L3 / R3 (stick clicks) | LS / RS | L3 / R3 |

### DS4Windows setup
- Set the output to **Xbox 360**. **Don't use DualShock 4 output**: Unity misreads the virtual DS4, so L1 registers as LT and rebinding saves the wrong buttons. PS icons come from this patch, not the output type.
- Turn on **Hide DS4 Controller** (HidHide) so the game only sees the virtual pad.
- Tip: in DS4Windows **Auto Profiles**, load your Xbox profile automatically when `MIMESIS.exe` runs.
- After switching, use **Reset keys** in the game's controls menu, since old binds may have saved the wrong buttons.

`Player.log` gets a `[PSController] Gamepads: ...` line listing what the game sees and which pad it uses. To log every button press, create an empty `MIMESIS_Data/PSIcons/debug.txt`; delete it when you're done.

## What it changes
- Injects a call to `PSController.PSIcons.Get` at the start of `KeyImageData.GetKeyImage(string)`. Every key prompt in the game goes through it. Gamepad keys (`p_*`) return a PS icon; everything else falls through to the game.
- Replaces every `Gamepad.current` read with `PSController.Pads.Current`, which returns the XInput (Xbox) pad when one exists.
- Adds `MIMESIS_Data/Managed/PSControllerRuntime.dll` and the icons in `MIMESIS_Data/PSIcons/`. You can replace those PNGs (74×74) with your own.

Uninstall removes both hooks, the DLL and the icons, and keeps other patches like BiggerLobby.

## Layout
- `Runtime/`: the icon loader (`PSControllerRuntime.dll`, netstandard2.1)
- `Patcher/`: the exe; it embeds the runtime DLL and icons
- `Icons/`: the PNGs, generated by `make_icons.py` from the game's own Xbox icons so they match the style

## Build
Build `Runtime` first (`dotnet build -c Release`), then `dotnet publish -c Release` in `Patcher`.
